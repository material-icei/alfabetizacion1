Tiene un menú con los 4 laberintos. Cada uno se juega así:

Lápiz en 4 colores para trazar el camino.
Goma: borra solo lo que dibujó el chico, nunca el laberinto.
Borrar todo: limpia el dibujo y pide confirmación antes.
¡Terminé!: muestra estrellas y un sonido, y pide “Mostrale tu camino a la seño”. No revisa si el camino es correcto.

Para agregar laberintos nuevos: copiá la imagen en la carpeta laberintos/ y sumá un bloque en data.js con imagen, titulo y consigna.
